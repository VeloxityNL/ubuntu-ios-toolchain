# Security Policy

## Reporting a vulnerability

Please do not publish credentials, signing keys, provisioning profiles, tokens, or other secrets in an issue.

For ordinary bugs that do not expose sensitive information, use GitHub Issues. If a report contains a secret, revoke or rotate that secret before sharing sanitized diagnostic information.

## Secrets this project never needs from contributors

Never commit or upload your Apple private key (`.p8`), signing certificates (`.p12`), provisioning profiles, SSH private keys, passwords, or access tokens to this repository.
