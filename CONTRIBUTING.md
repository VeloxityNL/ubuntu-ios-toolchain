# Contributing

Thanks for helping make iOS development on Ubuntu more accessible.

## Before opening an issue

Run `ubuntu-ios doctor` and include the relevant output. Never post Apple private keys, signing certificates, provisioning profiles, passwords, tokens, or other credentials.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep Ubuntu 24.04 compatibility in mind.
3. Run `bash -n install-ubuntu.sh ubuntu-ios ship.sh` for shell changes.
4. Explain what changed and how you tested it.

Bug reports, documentation improvements, compatibility fixes, and reproducible installation feedback are welcome.
